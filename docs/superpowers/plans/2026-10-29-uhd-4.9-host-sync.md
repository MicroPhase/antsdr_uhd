**Goal:** Replace the legacy UHD 4.1/4.4-derived host implementation on branch `uhd_4.9` with the Ettus UHD 4.9 host baseline while preserving and adapting AntSDR E200, E316/E310V2-compatible, U220, and U200 support.

**Architecture:** Use `/home/wcc/wcc_demo/tmp/uhd` at commit `cf78e1cfd` on branch `UHD-4.9` as the upstream host baseline. Keep AntSDR support isolated in the existing `host/lib/usrp/ant` backend and in narrowly scoped adaptations to shared B200/common code; do not carry forward the legacy whole-tree `uhd44_microphase.diff` approach. Preserve firmware and repository-level content outside `host/` unless the host build requires a specific interface update.

**Tech Stack:** CMake, C++17, UHD 4.9 host libraries, Boost, libusb, pybind11, existing AntSDR UDP transport and AD9361 control path, CTest/unit tests.

**Spec:** Approved migration design in the conversation on 2026-10-29.

## Global Constraints

- Upstream baseline is the local Ettus checkout `/home/wcc/wcc_demo/tmp/uhd`, branch `UHD-4.9`, commit `cf78e1cfd`.
- Preserve AntSDR device support and current device-lock behavior.
- Keep `ENABLE_ANT` explicit and independently switchable in CMake.
- Do not modify firmware unless a host/API compatibility issue proves it necessary.
